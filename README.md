  Biblioteca Fácil

Projeto acadêmico de um sistema para gerenciamento de livros.

AC1 - Cadastro e listagem de livros

A primeira funcionalidade desenvolvida permite:
    
    Cadastrar livros informando título e autor.
    Armazenar os livros em um banco de dados PostgreSQL.
    Listar os livros cadastrados na página inicial.

Tecnologias utilizadas:

      Python
      Flask
      HTML
      PostgreSQL
      psycopg2

Estrutura:

  O projeto utiliza três camadas:

    Front-end: HTML
    
    Back-end: Python com Flask
    
    Banco de dados: PostgreSQL
